SQL-Spickzettel (SQLite)

Reihenfolge der Klauseln in einer Abfrage: SELECT, FROM, WHERE, GROUP BY, HAVING, ORDER BY, LIMIT. Anweisungen enden mit einem Semikolon. Texte stehen in einfachen Anführungszeichen: 'Berlin'.

SELECT

SELECT spalte1, spalte2 FROM tabelle;
SELECT * FROM tabelle;
SELECT DISTINCT stadt FROM schueler;          -- Duplikate entfernen
SELECT name AS schuelername FROM schueler;    -- Alias
SELECT name, punkte * 2 AS doppelt FROM test; -- berechnete Spalte
SELECT vorname || ' ' || nachname FROM person; -- Texte verketten

WHERE

BedingungBeispiel / Bedeutung

AND, OR, NOTWHERE klasse = '10a' AND punkte > 50 (AND bindet stärker als OR; im Zweifel Klammern setzen)
BETWEEN a AND bGrenzen eingeschlossen: WHERE punkte BETWEEN 10 AND 20
IN (...)WHERE stadt IN ('Berlin', 'Potsdam')
LIKE% = beliebig viele Zeichen, _ = genau ein Zeichen: WHERE name LIKE 'M%'
IS NULL, IS NOT NULLfehlende Werte prüfen (nicht mit = NULL!)

ORDER BY und LIMIT

SELECT name, punkte FROM test ORDER BY punkte DESC, name ASC;  -- ASC ist Standard
SELECT * FROM test ORDER BY punkte DESC LIMIT 3;                -- die 3 besten
SELECT * FROM test LIMIT 10 OFFSET 20;                          -- ab dem 21. Datensatz

Aggregatfunktionen

FunktionBeschreibung
COUNT(*)Anzahl der Zeilen
COUNT(spalte)Anzahl der Zeilen, in denen spalte nicht NULL ist
COUNT(DISTINCT spalte)Anzahl verschiedener Werte
SUM(spalte), AVG(spalte)Summe bzw. Mittelwert (NULL-Werte werden ignoriert)
MIN(spalte), MAX(spalte)kleinster bzw. größter Wert

GROUP BY und HAVING

GROUP BY fasst Zeilen mit gleichem Wert zu Gruppen zusammen. WHERE filtert Zeilen vor dem Gruppieren, HAVING filtert Gruppen danach und darf Aggregatfunktionen enthalten.

SELECT klasse, COUNT(*) AS anzahl, AVG(punkte) AS schnitt
FROM schueler
WHERE aktiv = 1
GROUP BY klasse
HAVING COUNT(*) > 5
ORDER BY schnitt DESC;

Alle Spalten im SELECT, die nicht aggregiert sind, gehören in das GROUP BY.

JOIN-Arten

SELECT s.name, k.bezeichnung
FROM schueler s
INNER JOIN kurs k ON s.kurs_id = k.id;
ArtErgebnis
INNER JOIN (oder nur JOIN)nur Zeilen, zu denen es in beiden Tabellen einen Partner gibt
LEFT JOIN (LEFT OUTER JOIN)alle Zeilen der linken Tabelle; ohne Partner stehen in den Spalten der rechten Tabelle NULL-Werte
RIGHT JOINalle Zeilen der rechten Tabelle (in SQLite erst ab Version 3.39; sonst Tabellen vertauschen und LEFT JOIN nutzen)
FULL OUTER JOINalle Zeilen beider Tabellen (ebenfalls erst ab SQLite 3.39)
CROSS JOINkartesisches Produkt: jede Zeile mit jeder

Ohne Bedingung entsteht ein kartesisches Produkt. Mehrere Tabellen werden mit weiteren JOIN ... ON ... angehängt. Gleiche Spaltennamen werden mit tabelle.spalte bzw. dem Alias unterschieden. Zeilen ohne Partner finden: LEFT JOIN ... WHERE rechts.id IS NULL.

Unterabfragen

-- als Wert (liefert genau eine Zahl)
SELECT name FROM schueler WHERE punkte > (SELECT AVG(punkte) FROM schueler);

-- als Liste mit IN
SELECT name FROM schueler WHERE kurs_id IN (SELECT id FROM kurs WHERE fach = 'Informatik');

-- mit EXISTS
SELECT k.bezeichnung FROM kurs k
WHERE EXISTS (SELECT 1 FROM schueler s WHERE s.kurs_id = k.id);

-- als Tabelle in FROM
SELECT t.klasse, t.schnitt FROM (SELECT klasse, AVG(punkte) AS schnitt FROM schueler GROUP BY klasse) AS t;

Mengenoperationen: UNION (ohne Duplikate), UNION ALL, INTERSECT, EXCEPT. Beide Abfragen brauchen gleich viele Spalten.

INSERT, UPDATE, DELETE

INSERT INTO schueler (name, klasse, punkte) VALUES ('Mia', '10a', 12);
INSERT INTO schueler VALUES (NULL, 'Ben', '10b', 9, 2);   -- alle Spalten in Tabellenreihenfolge

UPDATE schueler SET punkte = punkte + 1 WHERE klasse = '10a';

DELETE FROM schueler WHERE id = 7;

Ohne WHERE betreffen UPDATE und DELETE alle Zeilen der Tabelle.

CREATE TABLE mit Schlüsseln

CREATE TABLE kurs (
    id          INTEGER PRIMARY KEY,
    bezeichnung TEXT NOT NULL UNIQUE
);

CREATE TABLE schueler (
    id      INTEGER PRIMARY KEY AUTOINCREMENT,
    name    TEXT NOT NULL,
    klasse  TEXT,
    punkte  INTEGER DEFAULT 0 CHECK (punkte >= 0),
    kurs_id INTEGER,
    FOREIGN KEY (kurs_id) REFERENCES kurs(id)
);

-- zusammengesetzter Primärschlüssel
CREATE TABLE belegung (
    schueler_id INTEGER,
    kurs_id     INTEGER,
    PRIMARY KEY (schueler_id, kurs_id)
);

SQLite-Besonderheiten

  • Datentypen: Spalten haben nur einen Typbezug (INTEGER, REAL, TEXT, BLOB, NUMERIC); SQLite prüft Typen nur schwach und speichert auch einen Text in einer INTEGER-Spalte, wenn er sich nicht umwandeln lässt. Es gibt keinen eigenen Datentyp für Wahrheitswerte (0 und 1) und für Datum/Uhrzeit (als Text, z. B. '2025-03-14').
  • Automatische Nummern: Eine Spalte INTEGER PRIMARY KEY zählt beim Einfügen von selbst hoch (AUTOINCREMENT verhindert zusätzlich die Wiederverwendung gelöschter Nummern).
  • Fremdschlüssel werden nur geprüft, wenn PRAGMA foreign_keys = ON; gesetzt ist.
  • Ganzzahldivision: 7 / 2 ergibt 3; für 3.5 schreibe 7 / 2.0.
  • Texte verketten mit || (nicht mit +). LIKE ignoriert Groß-/Kleinschreibung bei ASCII-Buchstaben.
  • Zeilen begrenzen mit LIMIT (es gibt kein TOP).
  • Nützliche Funktionen: COALESCE(a, b) / IFNULL(a, b) (Ersatzwert für NULL), LENGTH(text), UPPER(text), LOWER(text), SUBSTR(text, start, laenge) (Start ab 1), ROUND(x, stellen), ABS(x), date('now'), strftime('%Y', datum).
  • Fallunterscheidung: CASE WHEN punkte >= 10 THEN 'bestanden' ELSE 'nicht bestanden' END
  • Tabellen und Aufbau anzeigen: SELECT name FROM sqlite_master WHERE type = 'table'; und PRAGMA table_info(tabelle);
