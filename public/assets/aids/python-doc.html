Zeichenketten (str)

Unveränderlich; Index ab 0, negative Indizes zählen von hinten (s[-1] ist das letzte Zeichen). Ausschnitte: s[von:bis] (ohne bis), s[::-1] kehrt um.

MethodeBeschreibung
s.upper(), s.lower()Groß- bzw. Kleinschreibung
s.capitalize(), s.title()erster Buchstabe bzw. jedes Wort groß
s.strip(), s.lstrip(), s.rstrip()Leerraum an beiden Enden, links bzw. rechts entfernen
s.split(trenner=None)Liste der Teile; ohne Argument an Leerraum
trenner.join(liste)fügt Strings mit Trenner zusammen
s.replace(alt, neu)ersetzt alle Vorkommen
s.find(t), s.index(t)Position des ersten Vorkommens; find liefert -1, index löst ValueError aus
s.count(t)Anzahl der (nicht überlappenden) Vorkommen
s.startswith(t), s.endswith(t)Anfang bzw. Ende prüfen
s.isdigit(), s.isalpha(), s.isalnum()nur Ziffern / Buchstaben / beides?
s.format(...)Platzhalter {} füllen; kürzer mit f-String: f"{name}: {wert:.2f}"

Listen (list)

Veränderlich, Index ab 0. Ausschnitte wie bei Strings. Listenfassung: [x*x for x in range(5) if x != 2]

MethodeBeschreibung
l.append(x)hängt x hinten an
l.extend(iterable)hängt alle Elemente an
l.insert(i, x)fügt x vor Position i ein
l.remove(x)entfernt das erste Vorkommen von x (ValueError, wenn es fehlt)
l.pop(i=-1)entfernt das Element an Position i (Standard: letztes) und liefert es
l.index(x)Position des ersten Vorkommens (ValueError, wenn es fehlt)
l.count(x)Anzahl der Vorkommen
l.sort(key=None, reverse=False)sortiert die Liste selbst, liefert None
l.reverse()kehrt die Liste selbst um
l.copy()flache Kopie
l.clear()leert die Liste
del l[i]löscht das Element an Position i

Dictionaries (dict)

Schlüssel-Wert-Paare; Schlüssel sind eindeutig und unveränderlich (z. B. Zahlen, Strings, Tupel). Zugriff d[k] löst KeyError aus, wenn k fehlt.

MethodeBeschreibung
d.get(k, standard=None)Wert oder standard, wenn der Schlüssel fehlt
d.keys(), d.values(), d.items()Schlüssel, Werte bzw. (Schlüssel, Wert)-Paare
d.pop(k, standard)entfernt den Eintrag und liefert den Wert
d.update(anderes)übernimmt Einträge aus einem anderen Dictionary
d.setdefault(k, standard)liefert den Wert; legt ihn mit standard an, wenn k fehlt
k in dSchlüssel vorhanden?
del d[k]löscht den Eintrag
for name, punkte in d.items():
    print(name, punkte)
