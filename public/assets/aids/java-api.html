Java-API (Auszug)

Die wichtigsten Klassen und Methoden. java.lang (String, Math, Integer, System) ist immer verfügbar; Scanner, ArrayList, HashMap und Arrays brauchen einen import aus java.util.

String

Zeichenketten sind unveränderlich: Methoden liefern ein neues Objekt. Zeichen werden ab Index 0 gezählt.

MethodeBeschreibung
int length()Anzahl der Zeichen
char charAt(int index)Zeichen an der Stelle index (0 bis length()-1)
String substring(int von)Teilstring ab von bis zum Ende
String substring(int von, int bis)Teilstring von von bis vor bis
int indexOf(String s)Index des ersten Vorkommens, -1 wenn nicht enthalten (auch mit char)
int lastIndexOf(String s)Index des letzten Vorkommens, -1 wenn nicht enthalten
boolean equals(Object o)inhaltlicher Vergleich (nicht == verwenden)
boolean equalsIgnoreCase(String s)Vergleich ohne Beachtung der Groß-/Kleinschreibung
int compareTo(String s)lexikographischer Vergleich: negativ (kleiner), 0 (gleich), positiv (größer)
boolean contains(CharSequence s)true, wenn s enthalten ist
boolean startsWith(String s) / endsWith(String s)Anfang bzw. Ende prüfen
boolean isEmpty() / isBlank()Länge 0 bzw. nur Leerraum
String toUpperCase() / toLowerCase()Groß- bzw. Kleinschreibung
String trim() / strip()Leerraum am Anfang und Ende entfernen
String replace(CharSequence alt, CharSequence neu)ersetzt alle Vorkommen (auch mit char)
String[] split(String regex)zerlegt an Trennmustern, z. B. split(" ")
char[] toCharArray()Zeichen als Feld
String repeat(int n)n-fache Wiederholung
static String valueOf(x)wandelt einen Wert in einen String um
static String format(String fmt, Object... args)formatierter String wie printf
static String join(CharSequence trenner, CharSequence... teile)fügt Teile mit Trenner zusammen

Math

Methode / KonstanteBeschreibung
Math.abs(x)Betrag (int, long, float, double)
Math.max(a, b) / Math.min(a, b)größerer bzw. kleinerer Wert
double Math.pow(double a, double b)a hoch b
double Math.sqrt(double a)Quadratwurzel (NaN bei negativem Argument)
double Math.cbrt(double a)dritte Wurzel
long Math.round(double a)auf ganze Zahl runden (ab .5 auf)

Math.PI, Math.EKonstanten π und e

Zufallszahl von 1 bis 6: int w = (int) (Math.random() * 6) + 1;

Scanner (java.util.Scanner)

import java.util.Scanner;
Scanner sc = new Scanner(System.in);
int n = sc.nextInt();
MethodeBeschreibung
int nextInt()liest die nächste ganze Zahl
double nextDouble()liest die nächste Kommazahl (Schreibweise abhängig von der Spracheinstellung, oft mit Komma)
boolean nextBoolean()liest true oder false
String next()liest das nächste Wort (bis zum Leerraum)
String nextLine()liest den Rest der aktuellen Zeile
boolean hasNext() / hasNextInt() / hasNextLine()prüft, ob noch eine Eingabe dieser Art folgt
void close()schließt den Scanner

Achtung: Nach nextInt() bleibt der Zeilenumbruch in der Eingabe. Wer danach eine ganze Zeile braucht, ruft nextLine() einmal zusätzlich auf, um ihn zu verwerfen.

ArrayList<E> (java.util.ArrayList)

Dynamische Liste, Index ab 0. Elementtypen sind Klassen (Integer statt int).

MethodeBeschreibung
boolean add(E e)hängt e hinten an
void add(int index, E e)fügt e an der Stelle index ein, spätere Elemente rücken auf
E get(int index)liefert das Element an der Stelle index
E set(int index, E e)ersetzt das Element, liefert das alte zurück
E remove(int index)entfernt das Element an der Stelle index und liefert es zurück
boolean remove(Object o)entfernt das erste Vorkommen von o
int size()Anzahl der Elemente
boolean isEmpty()true bei leerer Liste
boolean contains(Object o)true, wenn o enthalten ist
int indexOf(Object o)Index des ersten Vorkommens, -1 wenn nicht enthalten
void clear()leert die Liste
void sort(Comparator c)sortiert, mit null in natürlicher Ordnung
ArrayList<String> namen = new ArrayList<>();
namen.add("Mia");
for (String n : namen) { System.out.println(n); }

HashMap<K,V> (java.util.HashMap)

Abbildung von Schlüsseln auf Werte, jeder Schlüssel höchstens einmal. Die Reihenfolge der Einträge ist nicht festgelegt.

MethodeBeschreibung
V put(K key, V value)speichert den Wert, liefert den früheren Wert oder null
V get(Object key)liefert den Wert oder null, wenn der Schlüssel fehlt
V getOrDefault(Object key, V standard)Wert oder standard
boolean containsKey(Object key)Schlüssel vorhanden?
boolean containsValue(Object value)Wert vorhanden?
V remove(Object key)entfernt den Eintrag, liefert den Wert oder null
int size() / boolean isEmpty()Anzahl der Einträge / leer?
Set<K> keySet()alle Schlüssel
Collection<V> values()alle Werte
Set<Map.Entry<K,V>> entrySet()alle Einträge, mit getKey() und getValue()
void clear()leert die Abbildung
HashMap<String, Integer> punkte = new HashMap<>();
punkte.put("Mia", 12);
for (String k : punkte.keySet()) { System.out.println(k + ": " + punkte.get(k)); }

Arrays (java.util.Arrays)

Die Länge eines Feldes steht in der Eigenschaft a.length (ohne Klammern).

MethodeBeschreibung
static String toString(int[] a)Feld als Text, z. B. [3, 1, 2] (für alle Feldtypen)
static void sort(int[] a)sortiert aufsteigend (auch sort(a, von, bis))
static void fill(int[] a, int wert)füllt das ganze Feld mit wert
static int[] copyOf(int[] a, int neueLaenge)Kopie mit neuer Länge (kürzer: abgeschnitten, länger: mit 0 aufgefüllt)
static int[] copyOfRange(int[] a, int von, int bis)Kopie des Bereichs von von bis vor bis
static boolean equals(int[] a, int[] b)gleiche Länge und gleiche Elemente?
static int binarySearch(int[] a, int key)Binärsuche, das Feld muss sortiert sein; Index oder negativer Wert, wenn nicht gefunden
static <T> List<T> asList(T... a)Liste fester Größe über den Elementen

Integer, Double und Character

Methode / KonstanteBeschreibung
static int Integer.parseInt(String s)String in int umwandeln; NumberFormatException bei ungültiger Eingabe
static double Double.parseDouble(String s)String in double umwandeln (Dezimalpunkt)
static Integer Integer.valueOf(int i)Umhüllung als Objekt
static String Integer.toString(int i)Zahl als Text
static String Integer.toBinaryString(int i) / toHexString(int i)Dualdarstellung bzw. Hexadezimaldarstellung
static int Integer.compare(int a, int b)negativ, 0 oder positiv
Integer.MAX_VALUE / Integer.MIN_VALUE2147483647 bzw. -2147483648
Character.isDigit(c), isLetter(c)Ziffer bzw. Buchstabe?
Character.isUpperCase(c), toUpperCase(c)Großbuchstabe prüfen bzw. umwandeln

System.out

MethodeBeschreibung
System.out.println(x)gibt x aus und beginnt eine neue Zeile
System.out.print(x)gibt x ohne Zeilenumbruch aus
System.out.printf(String fmt, Object... args)formatierte Ausgabe
System.currentTimeMillis()Millisekunden seit 1.1.1970
System.exit(int status)beendet das Programm (0 = ohne Fehler)

Formatangaben für printf: %d ganze Zahl, %f Kommazahl (%.2f mit zwei Nachkommastellen), %s Text, %c Zeichen, %b Wahrheitswert, %x hexadezimal, %5d mindestens 5 Stellen breit, %-8s linksbündig, %n Zeilenumbruch.

System.out.printf("%s hat %d Punkte (%.1f %%)%n", name, punkte, prozent);
